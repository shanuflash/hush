# Hush

Mute your mic system-wide with a mouse button. Works in Discord, games, the browser, anything that uses your microphone.

Tiny Windows tray app. One exe, no installer.

## Usage

Run `Hush.exe`. A mic icon shows up in the tray, green when live and red when muted.

Press the back side button on your mouse to mute or unmute. Right-click the tray icon to change the hotkey and other settings.

## Building

Needs Visual Studio Build Tools with the C++ workload. Then:

```
build.bat
```
